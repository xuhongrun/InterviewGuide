# 数据结构与算法

> 面试高频核心：复杂度 → 线性结构 → 树/图 → 算法范式 → 高频题型 → 刷题方法。

---

## 1. 复杂度分析

| 记号 | 含义 |
|------|------|
| `O(f)` | 上界（最差） |
| `Θ(f)` | 紧界（同阶） |
| `Ω(f)` | 下界 |

* **常见量级**：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)。
* **均摊复杂度**：vector push_back 均摊 O(1)（虽然偶尔扩容 O(n)）。
* **空间复杂度**：注意递归栈深度（DFS 容易爆栈）。
* **稳定性**：相同 key 相对顺序保持 → 稳定排序（mergesort、tim、insert）；不稳定（quick、heap）。

## 2. 线性结构

### 2.1 数组

* 连续内存，O(1) 随机访问，O(n) 插删。
* 动态数组（`vector` / `list`）：扩容 1.5x（VC）或 2x（GCC）。
* **双指针**：左右逼近、快慢指针、滑动窗口。
* **前缀和 / 差分**：区间和 / 区间加法 O(1)。

### 2.2 链表

* 单链表 / 双链表 / 循环链表。
* **快慢指针**：判环（Floyd）、找中点、找倒数第 K。
* **dummy head** 简化插入删除边界。
* 反转链表（迭代 + 递归两种写法必背）。

### 2.3 栈与队列

* 栈：括号匹配、表达式求值、单调栈（下一更大元素）。
* 队列：BFS、滑动窗口最值（**单调队列**）。
* **双端队列 deque**：单调队列底层。
* **优先队列 / 堆**：Top-K、Dijkstra、合并 K 个有序链表。

### 2.4 哈希表

* 开放寻址 vs 链地址（C++ unordered_map = 链地址 + 桶）。
* 平均 O(1)，最差 O(n)；负载因子超阈值 rehash。
* **冲突解决**：链表 / 红黑树（Java HashMap，桶 ≥ 8 转树）。
* 应用：去重、计数、缓存（LRU = HashMap + 双向链表）。

---

## 3. 树

### 3.1 二叉树

* 遍历：前 / 中 / 后序（递归 + 迭代）、层序（BFS）。
* **完全二叉树**：除最后一层外满，最后一层从左排列 → 数组存储。
* **平衡 BST**：AVL（严格 ±1）/ 红黑树（弱平衡，插删快）。
* **B / B+ 树**：磁盘友好，多路；MySQL InnoDB 索引用 B+ 树（叶子链表，范围查询快）。

### 3.2 堆

* 数组实现的完全二叉树；父 `i`，左 `2i+1`，右 `2i+2`。
* 建堆 O(n)（自底向上下沉）；插入/删除 O(log n)。
* **小顶堆求 Top K 最大**（堆大小 K，新元素 > 堆顶才换入）。

### 3.3 字典树 Trie

前缀匹配 / 自动补全 / IP 路由表。空间换时间，节点 O(字母表大小)。

### 3.4 并查集 Union-Find

* `find` + 路径压缩；`union` 按秩合并。
* 接近 O(α(n)) ≈ O(1)。
* 应用：Kruskal MST、连通分量、岛屿合并。

### 3.5 线段树 / 树状数组

* 区间和 / 区间最值 / 单点修改：BIT（Fenwick）O(log n)。
* 区间修改 + 区间查询：线段树 + 懒标记。

## 4. 图

### 4.1 表示

* 邻接矩阵 O(V²)，密集图。
* 邻接表 O(V+E)，稀疏图常用。

### 4.2 遍历

* **DFS**：递归 / 显式栈，时间 O(V+E)。
* **BFS**：队列；无权图最短路。

### 4.3 最短路

| 算法 | 适用 | 复杂度 |
|------|------|--------|
| BFS | 无权 | O(V+E) |
| Dijkstra | 非负权 | O((V+E) log V) 堆优化 |
| Bellman-Ford | 有负权 | O(VE) |
| SPFA | 负权 + 平均较快 | 最差 O(VE) |
| Floyd | 全源 | O(V³) |
| A* | 启发式 | 依赖启发函数 |

### 4.4 最小生成树

* **Kruskal**：边排序 + 并查集，O(E log E)。
* **Prim**：点扩展 + 优先队列，O((V+E) log V)。

### 4.5 拓扑排序

* Kahn（入度 BFS）/ DFS 后序逆。
* 检测环、任务调度、依赖解析。

### 4.6 强连通分量

Tarjan / Kosaraju O(V+E)。

## 5. 算法范式

### 5.1 双指针 / 滑动窗口

* 有序数组两数之和；无重复字符最长子串；最小覆盖子串。

### 5.2 二分查找

* 模板要分清：找等于 / 找左边界 / 找右边界。
* **答案二分**：求满足条件的最小/最大值（kth、分割数组最大和）。

```cpp
int lower_bound(vector<int>& a, int t) {
    int l = 0, r = a.size();   // 左闭右开
    while (l < r) {
        int m = l + (r - l) / 2;
        if (a[m] < t) l = m + 1;
        else r = m;
    }
    return l;
}
```

### 5.3 排序

| 算法 | 平均 | 最差 | 空间 | 稳定 | 备注 |
|------|------|------|------|------|------|
| 冒泡 / 选择 / 插入 | O(n²) | O(n²) | O(1) | 选择不稳定 | 教学 |
| 归并 | O(n log n) | O(n log n) | O(n) | ✅ | 链表友好 / 外排序 |
| 快排 | O(n log n) | O(n²) | O(log n) | ❌ | 三路分区抗重复 |
| 堆排 | O(n log n) | O(n log n) | O(1) | ❌ | 无递归 |
| 计数 / 桶 / 基数 | O(n+k) | O(n+k) | O(n+k) | ✅ | 整数受值域限制 |
| Tim | O(n log n) | O(n log n) | O(n) | ✅ | Python / Java 默认 |

### 5.4 分治

归并、快排、最近点对、大整数乘法（Karatsuba）。

### 5.5 贪心

跳跃游戏、区间调度、霍夫曼编码、Dijkstra。
**关键**：证明每步最优 → 全局最优（反证 / 交换论证）。

### 5.6 回溯

子集 / 全排列 / N 皇后 / 数独。
**剪枝** 是关键：可行性、最优性、对称性。

### 5.7 动态规划 DP

* **三步**：状态定义 → 转移方程 → 边界。
* **优化**：滚动数组、状态压缩、单调队列优化、斜率优化。

| 类型 | 题目 |
|------|------|
| 线性 | LIS / LCS / 编辑距离 / 打家劫舍 |
| 区间 | 矩阵链 / 戳气球 / 回文分割 |
| 背包 | 0-1 / 完全 / 多重 / 分组 |
| 树形 | 没有上司的舞会 / 树直径 |
| 状压 | TSP / 棋盘覆盖 |
| 数位 | 数字范围内满足条件计数 |
| 概率 | 抛硬币、随机游走 |

```python
# LIS O(n log n)
def length_of_lis(a):
    tails = []
    for x in a:
        i = bisect.bisect_left(tails, x)
        if i == len(tails): tails.append(x)
        else: tails[i] = x
    return len(tails)
```

## 7. 经典数据结构必须能手写

* **LRU 缓存**：

```cpp
class LRUCache {
    int cap_;
    list<pair<int,int>> lst;
    unordered_map<int, list<pair<int,int>>::iterator> mp;
public:
    LRUCache(int c): cap_(c) {}
    int get(int k) {
        auto it = mp.find(k);
        if (it == mp.end()) return -1;
        lst.splice(lst.begin(), lst, it->second);
        return it->second->second;
    }
    void put(int k, int v) {
        if (auto it = mp.find(k); it != mp.end()) {
            it->second->second = v;
            lst.splice(lst.begin(), lst, it->second);
            return;
        }
        if ((int)lst.size() == cap_) {
            mp.erase(lst.back().first);
            lst.pop_back();
        }
        lst.emplace_front(k, v);
        mp[k] = lst.begin();
    }
};
```

## 8. 刷题方法论

* **分类专题**而非随机：先吃透一个 pattern（双指针 → 滑窗 → 二分 → DP）。
* **白板 / 自我口述**：能讲解状态定义和复杂度。
* **二刷**：第一次看答案理解；24h / 一周后 / 一月后再做。
* **错题本**：记录 bug、卡点、关键 trick。
* **资源**：LeetCode（Top 100/Top Interview 150）、Codeforces、《算法导论》《编程珠玑》《剑指 Offer》。
* **题量**：250–400 题 + 高频反复，远胜盲刷 1000。

## 10. Top 15 算法面试 Checklist

1. ☐ 复杂度（时间 + 空间）能立刻报。
2. ☐ 写代码前先画图 / 举例 / 跑一遍。
3. ☐ 边界：空、单元素、重复、负数、溢出（int * int → long）。
4. ☐ 二分模板分清"≤、<、左边界、右边界"。
5. ☐ DP 状态定义 + 转移方程先写注释。
6. ☐ 递归先写终止条件。
7. ☐ 链表 / 树用 dummy / 哨兵 简化边界。
8. ☐ DFS 注意栈深；必要时改 BFS / 迭代。
9. ☐ 哈希取模注意负数（Python 不用，C++ 注意）。
10. ☐ Top-K 用堆而非全排序。
11. ☐ 字符串题先想哈希 / 双指针 / KMP。
12. ☐ 区间问题考虑前缀和 / 差分 / 线段树。
13. ☐ 写完跑一组小用例 + 一组边界。
14. ☐ 主动说 trade-off（时间 vs 空间，可读性 vs 性能）。
15. ☐ 不会就坦白说思路 → 一起讨论，比硬装好。

## 面试速记

1. **vector 均摊 push_back O(1)**，扩容 2x。
2. **快慢指针**：判环、找中点、倒数 K。
3. **堆 Top-K**：求最大用小顶堆。
4. **B+ 树 vs B 树**：B+ 叶子链表，范围查询快，MySQL 选它。
5. **Dijkstra 不能负权**；负权用 Bellman-Ford / SPFA。
6. **拓扑排序**：Kahn 入度 BFS。
7. **LRU = HashMap + 双链表**；O(1) 读写。
8. **DP 三步**：状态 / 转移 / 边界。
9. **二分难点**：左闭右开 + lower_bound 模板。
10. **稳定排序**：merge / insert / tim；快排堆排不稳定。
11. **回溯 = DFS + 剪枝**；通用模板：选择 → 递归 → 撤销。
12. **位运算**：`x & (x-1)` 去最低位 1；`x & -x` 取最低位 1。
