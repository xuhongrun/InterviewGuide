## 总结

| 篇章 | 核心内容 | 关键 C++ 类 |
|------|---------|------------|
| 第一篇 | MPC 直觉与概念 | 一维小车仿真 |
| 第二篇 | 状态空间与预测矩阵 | `buildPredictionMatrices` |
| **第二·五篇** | **稳定性、终端约束、递归可行性** | **`MPCStabilityChecker`, `solveDARE`** |

| 第四篇 | OSQP 与软约束（+Move Blocking、显式 MPC） | `OSQPMPCSolver`, `ExplicitMPC` |
| 第五篇 | 非线性 MPC（+动力学/轮胎/摩擦圆） | `BicycleModel`, `HybridVehicleModel` |
| 第六篇 | 工程实践（+输出反馈、多频率接口） | `KalmanFilter`, `OutputMPC`, `DelayBuffer` |
| 第七篇 | 前沿专题（+LMI/分布式/异步/降级） | `TubeMPC`, `MPCFallbackController` |
| **第八篇** | **方法选择决策树（vs LQR/PID/Stanley/H∞）** | **量化对标 5 案例** |
| **第九篇** | **现场调试指南（仿真→HiL→实车）** | **`plot_cost_landscape`, 故障 SOP** |
| **第十篇** | **自动驾驶专题（Frenet/走廊/SCP）** | **`SCPMPC`, `ConvexCorridor`** |

**选择建议**：

```
你的系统    →  推荐方案
──────────────────────────────────────────────
线性 + 无约束    → 标准 LQR（MPC 退化为 LQR）
```
