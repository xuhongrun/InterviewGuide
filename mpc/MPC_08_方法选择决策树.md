# 第八篇：方法选择决策树 —— MPC vs LQR / PID / Pure Pursuit / Stanley / H∞

---

## 引言

面试官最常问：

> **"你为什么选 MPC？用 PID 不行吗？"**

如果你回答"MPC 更高级"——失分。如果回答"MPC 能处理约束"——刚及格。如果你能给出**量化对标 + 决策树 + 场景案例**——加分。

本篇提供一套**工程决策框架**，帮你回答"什么场景用什么控制器"，并附 5 个经典场景对比数据。

---

## 一、控制方法谱系总览

```
按设计哲学分类
═══════════════════════════════════════════════
反馈控制（Reactive）              规划-控制（Predictive/Optimal）
   ├─ PID                            ├─ LQR (无穷时域、无约束)
   ├─ Pure Pursuit (几何)            ├─ MPC (有限时域、有约束)
   ├─ Stanley (几何 + 偏航)          ├─ NMPC (非线性扩展)
   ├─ Bang-Bang (开关)               └─ DDP / iLQR (轨迹优化)
   ├─ Sliding Mode (滑模)
   └─ H∞ (鲁棒)                  数据驱动 / 学习
                                     ├─ MPC + GP (建模学习)
                                     ├─ Reinforcement Learning
                                     └─ Imitation Learning
```

## 三、决策树（4 层）

```
                       ┌─ 是约束敏感系统？─┐
                       │                      │
                      是                     否
                       │                      │
              ┌─实时要求？─┐         ┌─系统线性？─┐
              │              │            │           │
            <1ms         >1ms        是           否
              │              │            │           │
       显式MPC      ┌─线性？─┐      LQR / LQG    ┌─闭环系统？─┐
                    │        │                   │            │
                  是       否                  是          否
                    │        │                   │            │
              线性MPC    NMPC               PID 单输入    PID 多环
              + OSQP     + SLQ
                                              ↑           ↑
                                         调参容易    调参专业
```

### 3.1 决策树问题清单

**Q1：是否有约束？（必答）**

- "执行器有上下限"——所有真实系统都有，看你是否要*显式*处理
- "状态有安全边界"（如车不能跑出车道、机械臂关节限位）→ MPC

**Q2：实时性要求？**

- 控制率 > 1 kHz：PID / 显式 MPC
- 100 Hz ~ 1 kHz：线性 MPC + OSQP
- < 100 Hz：NMPC、Tube、Stochastic 都行

**Q3：系统是否线性？**

- 线性或弱非线性 → LQR / 线性 MPC
- 强非线性（车辆动力学、机器人多关节）→ NMPC 或 SLQ

**Q4：是否多输入耦合？**

- SISO（单输入单输出）→ PID 容易、足够
- MIMO（多输入多输出）→ LQR / MPC 自然处理

**Q5：是否需要预测性？**

- "需要规避未来某个障碍/变化"→ MPC 必需
- "只需对当前误差反应"→ PID 即可

**Q6：模型不准确？**

- 准确 → 任意方法
- 不准但有界 → Tube MPC / H∞
- 不准且未知分布 → Learning MPC / RL

## 四、场景案例对标（5 个案例）

### 案例 1：单关节机械臂位置控制

```
状态：θ（关节角度），ω（关节角速度）
输入：电机电压 V
约束：|V| ≤ 24V，|ω| ≤ 5 rad/s
要求：跟踪正弦轨迹 θ_ref(t) = sin(t)
```

| 方法 | 跟踪 RMSE (rad) | 调参时间 | 实现行数 |
|------|---------------|---------|---------|
| PID | 0.08 | 0.5 h | 30 |
| LQR | 0.02 | 1 h | 80 |
| 线性 MPC (N=10) | 0.015 | 4 h | 300 |

**结论**：单关节机械臂上 LQR 已经很好；MPC 仅在约束频繁激活（如电压饱和）时优势明显。

---

### 案例 2：自动驾驶横向控制（高速 80 km/h）

```
状态：横向偏差 e_y、偏航偏差 e_ψ、横向速度 v_y、偏航率 r
输入：转向角 δ
约束：|δ| ≤ 0.5 rad，|δ̇| ≤ 1 rad/s
要求：跟踪曲线半径 R = 200 m 的弧线
```

| 方法 | 横向 RMSE (m) | 高速稳定性 | 备注 |
|------|--------------|----------|------|
| Pure Pursuit | 0.45 | 易振荡 | 几何方法，高速忽略动力学 |
| Stanley | 0.30 | 中等 | 含偏航反馈，比 PP 稳 |
| LQR (动力学模型) | 0.12 | 好 | 无约束，无法处理 $\delta$ 限位 |
| MPC (动力学 + 5 步预瞄) | 0.08 | 优 | 显式约束 + 预瞄曲率 |

**结论**：高速车辆 MPC 显著优于 Pure Pursuit / Stanley。低速可用 PP（简单），高速必须 MPC。

---

### 案例 3：四旋翼悬停 + 路径跟踪

```
状态：[x, y, z, ϕ, θ, ψ, vx, vy, vz, p, q, r] (12 维)
输入：4 个电机推力
约束：每电机推力 [0, 4]N
要求：跟踪 8 字形轨迹
```

| 方法 | 跟踪 RMSE (m) | 计算时间 | 鲁棒性 |
|------|--------------|---------|------|
| 级联 PID（位置+姿态） | 0.20 | < 0.1 ms | 中 |
| LQR（线性化悬停点） | 0.15 | < 0.1 ms | 差（远离悬停发散） |
| NMPC (CasADi+IPOPT) | 0.05 | 8 ms | 优 |
| iLQR | 0.06 | 3 ms | 优 |

**结论**：强非线性 + 强耦合 → NMPC 或 iLQR 是教科书级正确选择。

---

### 案例 4：化工反应釜温度控制

```
状态：反应温度 T、催化剂浓度 C
输入：冷却液流量 Q
约束：|Q| ≤ Q_max，|T| ≤ T_safety
要求：抑制原料浓度变化的扰动
```

| 方法 | 稳态偏差 | 抗扰能力 | 工程难度 |
|------|---------|---------|---------|
| PID + 前馈 | < 1°C | 中 | 低 |
| Smith 预估器 + PI | < 0.5°C | 优（处理大延迟） | 中 |
| 工业 MPC（Aspen DMC） | < 0.3°C | 优 | 高 |

**结论**：传统过程控制中 MPC + 前馈非常成熟，但 PID + 前馈往往**已经足够**——不是所有问题都需要 MPC。

---

### 案例 5：受限运动规划（六轴机械臂避障）

```
状态：6 关节角与角速度（12 维）
输入：6 关节力矩
约束：关节限位、力矩极限、避免障碍物（非凸）
要求：从 A 抓取到 B 放置
```

| 方法 | 可行性 | 计算时间 | 备注 |
|------|------|---------|------|
| PID + 路径规划解耦 | 中 | < 1 ms | 路径规划离线，控制简单 |
| MPC (凸化障碍) | 优 | 30 ms | 把障碍凸化为多面体 |
| NMPC (SCP) | 优 | 200 ms | 直接处理非凸 |
| 强化学习 (DDPG) | 低 | < 1 ms 推理 | 训练数小时；零样本难收敛 |

**结论**：高维 + 非凸约束场景 → 规划层用搜索/采样，控制层用 MPC，**分层是王道**。

## 五、面试问答精华

### Q1：MPC 比 PID 强在哪？

> 三点：
> 1. **预测性**：MPC 看 $N$ 步未来，PID 只看当前误差，遇到大延迟系统 PID 必振荡
> 2. **约束**：PID 通过 anti-windup 处理饱和，但状态约束（如车不能出车道）无法表达
> 3. **多输入耦合**：MIMO 系统 PID 需要解耦设计，工作量大；MPC 天然处理

### Q2：那 PID 比 MPC 好在哪？

> 三点：
> 1. **不需要模型**——MPC 模型错就完蛋
> 2. **实时性极高**——单片机轻松 10 kHz
> 3. **调参直观**——P/I/D 三个旋钮，工程师都会调

### Q3：LQR 与 MPC 何时等价？

> 当 $N \to \infty$、终端代价 $Q_f = P_\infty$（DARE 解）、**且约束都不激活**时，MPC 退化为 LQR。  
> 反过来，**LQR 可以看作"无约束、无穷时域 MPC"**——这是 MPC_02_5 稳定性证明的核心。

### Q4：为什么 Pure Pursuit 在高速失效？

> Pure Pursuit 只用几何（前瞻点 + 圆弧），不考虑车辆动力学（侧偏、惯性）。低速时车辆动力学近似运动学，PP 准确；高速时动力学滞后导致 PP 命令的转向角无法及时产生预期横向位移，进而过转/欠转、振荡。

### Q5：H∞ 与 Tube MPC 都做鲁棒控制，区别？

> | | H∞ | Tube MPC |
> |----|----|----|
> | 约束 | 不显式处理 | 显式处理 |
> | 在线计算 | 增益预算（极快） | 求 QP（中等） |
> | 鲁棒模型 | 频域不确定性 | 时域有界扰动 |
> | 工业部署 | 飞行控制为主 | 自动驾驶/机器人 |
>
> 一句话：约束敏感选 Tube，不变性敏感选 H∞，二者甚至可以**串联**（H∞ 内环 + Tube MPC 外环）。

### Q6：你给一个新项目选 MPC 的检查清单？

> 7 步检查清单：
> 1. 系统模型是否能写出来？（不能 → PID 或 RL）
> 2. 是否有显式状态/输入约束？（无 → LQR）
> 3. 控制率要求？（> 1 kHz → 显式 MPC 或 PID）
> 4. CPU 算力？（MCU 无 FPU → 显式 MPC 或定点 PID）
> 5. 模型是线性还是非线性？（决定 MPC 还是 NMPC）
> 6. 扰动是有界还是随机？（决定 Tube vs Stochastic）
> 7. 团队是否有 MPC 经验？（无 → 先 PID 跑通再升级）

## 六、何时**不要**用 MPC

工程界 MPC "滥用"现象：

```
❌ 单关节伺服 + 无约束 → 用 PID 即可
❌ 慢过程（采样 1s）+ 简单跟踪 → PI + 前馈足够
❌ MCU 性能极弱（M0、无 FPU）+ 高频控制 → 显式 MPC 表大或 PID
❌ 模型不可获得且数据少 → RL 或自适应控制
❌ 强非线性但 NMPC 无法实时 → DDP / iLQR
❌ 团队完全没经验 + 项目工期紧 → 先 LQR 再说
```

## 总结

| 维度 | 选择原则 |
|------|---------|
| **约束** | 有约束且影响大 → MPC；不影响 → LQR/PID |
| **实时性** | < 1 ms → PID/显式 MPC；1~10 ms → 线性 MPC；> 10 ms → NMPC |
| **非线性** | 强 → NMPC/SLQ；弱 → 线性 MPC + 在线线性化 |
| **鲁棒性** | 有界扰动 → Tube；随机分布 → Stochastic；频域不确定 → H∞ |
| **维度** | 高维状态 → 分层（规划 + MPC）；低维 → 单层 MPC |
| **团队水平** | 新手 → PID/LQR 起步；熟练 → MPC；研究 → Tube/Learning |

> **黄金法则**：用最简单的能解决问题的方法。MPC 是**可选项**而非默认项；当 PID 撑不住或 LQR 无法表达约束时，MPC 才显示价值。
