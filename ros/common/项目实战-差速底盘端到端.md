# 项目实战：差速底盘端到端

> 一个完整的 ROS2 差速底盘项目：从 URDF → ros2_control → SLAM → Nav2 → bag → Docker → 部署。可用于面试讲项目时按层叙述。

---

## 一、项目目标

- 平台：两轮差速 + 万向轮，含 2D LiDAR + IMU + 编码器；
- 软件栈：ROS2 Jazzy + Cyclone DDS；
- 功能：建图 / 定位 / 自主导航 / 远程监控 / OTA。

## 四、Hardware Interface 实现

```cpp
class MyRobotHW : public hardware_interface::SystemInterface {
    CallbackReturn on_init(const HardwareInfo& info) override {
        cmd_vel_.resize(2, 0.0);
        pos_.resize(2, 0.0); vel_.resize(2, 0.0);
        serial_.open("/dev/ttyUSB0", 115200);
        return CallbackReturn::SUCCESS;
    }
    return_type read(...) override {
        auto enc = serial_.read_encoder();   // ticks
        for (int i=0;i<2;++i) {
            double new_pos = enc[i] * TICK_TO_RAD;
            vel_[i] = (new_pos - pos_[i]) / period.seconds();
            pos_[i] = new_pos;
        }
        return return_type::OK;
    }
    return_type write(...) override {
        serial_.write_velocity(cmd_vel_[0], cmd_vel_[1]);
        return return_type::OK;
    }
};
```

下位机协议（推荐）：CAN-FD 或 USB-CDC，二进制帧含 CRC + sequence。

## 五、Bringup launch（核心）

```python
def generate_launch_description():
    pkg = get_package_share_directory('my_robot_bringup')
    urdf = xacro.process_file(pkg + '/urdf/robot.urdf.xacro').toxml()

    return LaunchDescription([
        # 描述
        Node(package='robot_state_publisher', executable='robot_state_publisher',
             parameters=[{'robot_description': urdf}]),
        # 控制
        Node(package='controller_manager', executable='ros2_control_node',
             parameters=[{'robot_description': urdf}, pkg + '/config/controllers.yaml']),
        Node(package='controller_manager', executable='spawner',
             arguments=['joint_state_broadcaster']),
        Node(package='controller_manager', executable='spawner',
             arguments=['diff_drive_controller']),
        # 传感器
        IncludeLaunchDescription([pkg + '/launch/lidar.launch.py']),
        IncludeLaunchDescription([pkg + '/launch/imu.launch.py']),
        # EKF 融合
        Node(package='robot_localization', executable='ekf_node',
             parameters=[pkg + '/config/ekf.yaml']),
    ])
```

## 六、controllers.yaml

```yaml
controller_manager:
  ros__parameters:
    update_rate: 100
    use_sim_time: false
    joint_state_broadcaster: { type: joint_state_broadcaster/JointStateBroadcaster }
    diff_drive_controller:   { type: diff_drive_controller/DiffDriveController }

diff_drive_controller:
  ros__parameters:
    left_wheel_names: [left_wheel_joint]
    right_wheel_names: [right_wheel_joint]
    wheel_separation: 0.30
    wheel_radius: 0.08
    publish_rate: 50.0
    odom_frame_id: odom
    base_frame_id:  base_link
    enable_odom_tf: true       # ⚠️ 与 EKF 联用时改 false
    open_loop: false
    cmd_vel_timeout: 0.5
```

## 九、Nav2 配置要点

`nav2_params.yaml`：
- planner：Smac 2D / NavFn；
- controller：MPPI 或 RPP；
- BT：使用 `navigate_w_replanning_and_recovery.xml`；
- costmap：local 5x5 rolling，加 voxel_layer + inflation_layer；
- collision_monitor：前向多边形减速 / 急停。

启动：
```bash
ros2 launch my_robot_navigation bringup.launch.py map:=office.yaml
```

## 十一、Docker 部署

```dockerfile
FROM ros:jazzy-ros-base
ENV RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
ENV ROS_DOMAIN_ID=42

RUN apt-get update && apt-get install -y \
    ros-jazzy-rmw-cyclonedds-cpp \
    ros-jazzy-slam-toolbox \
    ros-jazzy-navigation2 ros-jazzy-nav2-bringup \
    ros-jazzy-robot-localization \
    ros-jazzy-ros2-control ros-jazzy-ros2-controllers \
    && rm -rf /var/lib/apt/lists/*

COPY src /ros2_ws/src
WORKDIR /ros2_ws
RUN . /opt/ros/jazzy/setup.sh && \
    rosdep install --from-paths src --ignore-src -y && \
    colcon build --symlink-install

ENTRYPOINT ["/ros_entrypoint.sh"]
CMD ["ros2", "launch", "my_robot_bringup", "bringup.launch.py"]
```

`docker run --network host --device=/dev/ttyUSB0 --restart=always my_robot:latest`。

## 十三、问题排查链路（面试常考）

| 现象 | 排查链 |
|------|--------|
| 机器人不动 | controller spawn? `/cmd_vel` 有数据? Hardware write 通? 串口权限? |
| 漂得厉害 | 编码器分辨率？wheel_radius 准？IMU 协方差？地面打滑？|
| 建图失败 | TF 全否？时间戳？scan 频率？odom 漂太快？ |
| Nav2 卡 | costmap 障碍残留？BT 进入 recovery 循环？collision_monitor 一直触发？ |
| QoS 不匹配 | RViz / Nav2 看不到 map（要 TRANSIENT_LOCAL）|

- URDF + ros2_control + diff_drive_controller 三件套打底盘
