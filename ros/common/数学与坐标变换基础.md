# 数学与坐标变换基础

> 机器人 / SLAM / 控制必备数学基础：旋转表示（欧拉角 / 旋转矩阵 / 四元数 / 轴角 / 李群李代数）、SE(3)、与 ROS TF 的对应关系。

---

## 一、旋转表示对比

| 表示 | 自由度 | 优点 | 缺点 |
|------|--------|------|------|
| 旋转矩阵 R∈SO(3) | 9 (3 自由度+6 约束) | 直接作用向量 | 冗余、需正交化 |
| 欧拉角 (roll/pitch/yaw) | 3 | 直观 | **万向锁**，旋转顺序歧义 |
| 轴角 (axis-angle) | 3 | 紧凑 | 旋转复合复杂 |
| 四元数 q=(w,x,y,z) | 4 (1 约束) | 无奇异、插值好（slerp） | 不直观 |
| 旋转向量 (Rodrigues) | 3 | 与轴角等价 | 同上 |

ROS 默认四元数 **(x,y,z,w)** 顺序（geometry_msgs/Quaternion）。Eigen 默认 **(w,x,y,z)** 构造，但内部存储 (x,y,z,w)。

## 二、欧拉角与万向锁

ROS 默认 **ZYX (yaw-pitch-roll)** 内旋约定：先绕 Z 转 yaw，再绕新 Y 转 pitch，最后绕新 X 转 roll。

```cpp
double r,p,y;
tf2::Matrix3x3(q).getRPY(r, p, y);
```

万向锁：当 pitch = ±π/2 时，roll 与 yaw 共线，丢一个自由度。**控制 / 估计避免欧拉角**，仅展示用。

## 三、四元数核心

定义：$q = w + xi + yj + zk$，单位四元数 $\|q\|=1$。

旋转向量 $v$：
$$v' = q \otimes \begin{bmatrix}0 \\ v\end{bmatrix} \otimes q^{-1}$$

复合：$q_{AC} = q_{AB} \otimes q_{BC}$（左乘）。

逆：$q^{-1} = (w, -x, -y, -z) / \|q\|^2$，单位四元数等价于共轭。

球面线性插值（slerp）：
$$\mathrm{slerp}(q_0, q_1, t) = \frac{\sin((1-t)\theta)}{\sin\theta}q_0 + \frac{\sin(t\theta)}{\sin\theta}q_1$$
其中 $\cos\theta = q_0 \cdot q_1$。

ROS 工具：
```cpp
tf2::Quaternion q; q.setRPY(0, 0, M_PI/4);
auto q_inv = q.inverse();
auto q_slerp = q0.slerp(q1, 0.5);
```

## 四、SO(3) / SE(3) 与齐次矩阵

SE(3) 齐次变换矩阵：
$$T = \begin{bmatrix} R & t \\ 0 & 1 \end{bmatrix} \in \mathbb{R}^{4 \times 4}$$

复合：$T_{AC} = T_{AB} T_{BC}$。

逆：
$$T^{-1} = \begin{bmatrix} R^T & -R^T t \\ 0 & 1 \end{bmatrix}$$

Eigen：
```cpp
Eigen::Affine3d T = Eigen::Translation3d(t) * Eigen::Quaterniond(q);
Eigen::Vector3d v_b = T.inverse() * v_a;
```

ROS：
```cpp
geometry_msgs::msg::TransformStamped tfmsg;
Eigen::Isometry3d T = tf2::transformToEigen(tfmsg);
```

## 五、李群与李代数

| 群 | 代数 |
|----|------|
| SO(3) | $\mathfrak{so}(3) = \mathbb{R}^3$（角速度向量） |
| SE(3) | $\mathfrak{se}(3) = \mathbb{R}^6$（线速度+角速度） |

指数映射 $\exp: \mathfrak{so}(3) \to SO(3)$（Rodrigues 公式）：
$$\exp([\omega]_\times) = I + \frac{\sin\theta}{\theta}[\omega]_\times + \frac{1-\cos\theta}{\theta^2}[\omega]_\times^2$$

对数映射反过来取角速度向量。SLAM 优化变量常用李代数（无奇异、维度最小）。

库：
- **Sophus**（C++）：`Sophus::SO3d`, `Sophus::SE3d`，`exp/log/Adj`；
- **manif**：替代库，模板化。

## 六、TF 在 ROS 中的语义

`TransformStamped`：从 `header.frame_id`（父）到 `child_frame_id`（子）的变换。

> 重要：把**点 p 在 child 系下的坐标**转到 **parent 系**：`p_parent = T_parent_child * p_child`。

代码：
```cpp
auto t = tf_buffer.lookupTransform("map", "base_link", tf2::TimePointZero);
geometry_msgs::msg::PointStamped p_in, p_out;
p_in.header.frame_id = "base_link";
p_in.point.x = 1.0;
tf2::doTransform(p_in, p_out, t);  // p_out 在 map 系
```

⚠️ 易错：`lookupTransform("base_link","map",...)` 与 `lookupTransform("map","base_link",...)` 方向相反，**目标系在前**。

## 七、坐标系约定

| 物体 | X | Y | Z |
|------|---|---|---|
| 机器人体（REP-103） | 前 | 左 | 上 |
| 相机（OpenCV） | 右 | 下 | 前 |
| 相机光学（ROS image） | 右 | 下 | 前（同 OpenCV） |
| 航空 NED | 北 | 东 | 下 |
| ENU | 东 | 北 | 上 |

相机外参常需 body→camera 的固定旋转：
```
T_body_camera = T(roll=-π/2) * T(yaw=-π/2)
```

## 八、常用变换公式

### 8.1 速度变换

机体速度 → 世界速度：
$$v_w = R_{wb} v_b, \quad \omega_w = R_{wb} \omega_b$$

### 8.2 雅可比（角速度积分）

四元数微分：
$$\dot{q} = \frac{1}{2} q \otimes \begin{bmatrix} 0 \\ \omega \end{bmatrix}$$

### 8.3 Adjoint（速度跨系）

$$\begin{bmatrix} v' \\ \omega' \end{bmatrix} = \mathrm{Ad}(T) \begin{bmatrix} v \\ \omega \end{bmatrix}, \quad \mathrm{Ad}(T) = \begin{bmatrix} R & [t]_\times R \\ 0 & R \end{bmatrix}$$

## 九、常见坑

| 错误 | 解决 |
|------|------|
| 用欧拉角做控制器状态 | 改四元数 / 李代数 |
| 四元数没归一化 | 每步 `q.normalize()` |
| `lookupTransform` 父子搞反 | 严格按 `target_frame, source_frame` 顺序 |
| Eigen 与 ROS 四元数顺序混 | Eigen 构造 `Quaterniond(w,x,y,z)`，ROS msg `(x,y,z,w)` |
| 点变换与变换链相乘混 | 点变换用 `T*p`；变换链 `T1*T2`，注意顺序 |

## 十、面试速记

- 四元数 ROS 顺序 **(x,y,z,w)**，Eigen 构造 **(w,x,y,z)**
- 欧拉角仅展示用，控制 / 估计用四元数或李代数
- TF 含义：**`p_parent = T_parent_child * p_child`**
- `lookupTransform(target, source, time)` —— 别搞反
- 库：tf2 / Eigen / **Sophus** / manif
- 相机系（X 右 Y 下 Z 前）与机体系（X 前 Y 左 Z 上）必须有固定外参
