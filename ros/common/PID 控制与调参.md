# PID 控制与调参

> 工程界最常用的反馈控制器：原理、变体、调参方法、抗饱和与工程化。

---

## 1. PID 直觉

```
       误差 e        ┌──── Kp·e ────┐
设定 r ──+── e ──┬──┤              ├── Σ ── u → 系统 → 反馈 y
         -        ├──┤ Ki·∫e dt   ├──┘
         y        └──┤ Kd·de/dt  ─┘
```

* **P (Proportional)**：当前误差 → 跟得快、稳态有偏差。
* **I (Integral)**：累计历史 → 消除稳态误差，但易超调 / 饱和 / 振荡。
* **D (Derivative)**：误差变化 → 抑制超调、加阻尼，但放大噪声。

连续：

$$ u(t) = K_p e(t) + K_i \int_0^t e(\tau) d\tau + K_d \frac{de(t)}{dt} $$

离散（位置式）：

$$ u_k = K_p e_k + K_i T_s \sum_{i=0}^k e_i + \frac{K_d}{T_s} (e_k - e_{k-1}) $$

---

## 2. 位置式 vs 增量式

| | 位置式 | 增量式 |
|---|--------|--------|
| 输出 | u 直接给 | Δu = u_k - u_{k-1} |
| 累积积分 | 需要 | 不需要（隐含在历史） |
| 抗扰动 | 切换瞬间易跳 | 平滑 |
| 误动作影响 | 全输出 | 单步 |
| 适用 | 阀门绝对开度 | 步进电机 / 速度环 / 多数实际 |

**工程更常用增量式**（特别是有累积器溢出风险时）：

$$ \Delta u_k = K_p (e_k - e_{k-1}) + K_i T_s e_k + \frac{K_d}{T_s} (e_k - 2e_{k-1} + e_{k-2}) $$

## 3. 调参方法

### 3.1 经验法（**最常用**）

按顺序：
1. **只开 P**：从小到大调 `Kp`，到出现等幅振荡或临界稳定 → 取约 0.5×。
2. **加 I 消静差**：`Ki` 从 0 起逐步增加，到稳态误差消失，但不能太大致超调。
3. **加 D 抑超调 / 抖**：`Kd` 从 0 起，缓解超调；噪声大时不加或加滤波。

### 3.2 Ziegler-Nichols 临界振荡法

* 仅开 P，逐步增大 Kp 到系统等幅振荡 → 临界增益 `Ku`，振荡周期 `Tu`。
* 取值（经典 Z-N）：

| 控制器 | Kp | Ti | Td |
|--------|----|----|----|
| P | 0.5 Ku | – | – |
| PI | 0.45 Ku | Tu/1.2 | – |
| PID | 0.6 Ku | Tu/2 | Tu/8 |

进阶：Tyreus-Luyben（更保守）；CHR（Chien-Hrones-Reswick）按超调要求。

### 3.3 阶跃响应法（开环辨识）

输入阶跃，记录响应，估计延迟 `L` 和时间常数 `T`、增益 `K`：

* 一阶 + 延时 (FOPDT)：`G(s) = K e^(-Ls) / (Ts+1)`。
* 用 Cohen-Coon / Z-N 第二法查表给初值。

### 3.4 自整定 / 模型参考

* 现代 PLC 自整定按钮（Beckhoff / Siemens / Rockwell）。
* 频域：相位裕度、增益裕度。
* 启发式：模拟退火 / 粒子群 / 强化学习（学界，工程少）。

## 4. 关键工程问题

### 4.1 积分饱和（Integral Windup）

执行器饱和时积分仍累积 → 解除饱和后超调严重。

**反 Windup 三招**：
1. **限幅积分**：`I = clamp(I, I_min, I_max)`。
2. **条件积分（Conditional Integration）**：饱和时停止积分。
3. **回路积分回退（Back-Calculation）**：`I += Kt * (u_sat - u)`。

```cpp
double pid(double e) {
    static double I = 0, e_prev = 0;
    double P = Kp * e;
    double D = Kd * (e - e_prev) / Ts;
    double u_pre = P + I + D;
    double u = clamp(u_pre, U_MIN, U_MAX);
    // back-calculation anti-windup
    I += Ki * Ts * e + Kt * (u - u_pre);
    e_prev = e;
    return u;
}
```

### 4.2 微分滤波 / 微分先行

D 项放大高频噪声 → 用一阶低通滤波：

$$ D_{filt}(s) = \frac{K_d s}{1 + (K_d / N) s} $$

`N` 取 8~20。或 **微分先行**：D 只对**反馈 y**求导（不对 r），避免设定值阶跃造成微分尖峰。

### 4.3 设定值斜坡

阶跃 r 突变 → 控制冲击。引入斜坡 / 二阶轨迹（梯形 / S 曲线）平滑设定值。

### 4.4 死区 / 滞回

误差小于 ε 时不调节，避免噪声引起执行器抖动 / 磨损。

### 4.5 采样周期

* 经验：`Ts ≤ T / 10`（被控时间常数的 1/10）。
* 太大：相位损失大，必须重调；太小：噪声放大、计算资源浪费。

### 4.6 执行器特性

* 响应时间、最大速率、死区、饱和 → 全部要建模 / 限制。
* 速率限制（rate limit）：`u_k = u_{k-1} + clamp(Δu, -Δmax, Δmax)`。

## 5. 变体

### 5.1 PI / PD

* PI：跟随精度高、无静差，无 D（噪声大场景）。
* PD：响应快、阻尼强；适合纯惯性 / 二阶系统。

### 5.2 串级 PID（Cascade）

* 内环（速度 / 电流）+ 外环（位置）；内环带宽远大于外环（5~10×）。
* 提高扰动抑制（内环吃干扰）+ 限速更自然。
* **实例**：电机：电流环 → 速度环 → 位置环；无人机：姿态角速率 → 姿态角 → 位置。

### 5.3 前馈 + PID

已知动力学模型 → 前馈给出"理想"控制量，PID 只负责修正误差。
**适用**：跟踪轨迹（已知期望加速度）、温度（已知热损失）。

```
u = u_ff(r, ṙ, r̈) + u_pid(e)
```

### 5.4 Gain Scheduling

不同工况切换不同 PID 参数：起飞 / 巡航 / 着陆 / 空载 / 满载。

### 5.5 自适应 / 模糊 / 神经网络 PID

* 自适应：根据误差实时调 Kp/Ki/Kd。
* 模糊 PID：用模糊规则查表选参数。
* 工程上不如 Cascade + 前馈 + 抗饱和"组合拳"实用。

## 6. 常见现象排查

| 现象 | 原因 | 调整 |
|------|------|------|
| 响应慢、跟不上 | Kp 小 / Ki 小 / 采样慢 | 加 Kp，再加 Ki |
| 振荡 / 不稳定 | Kp 大 / Kd 小 / 延时大 | 减 Kp，加 Kd / 滤波 |
| 超调大 | Kp 大 / Ki 大 / Kd 小 | 减 Ki、加 Kd、加设定值斜坡 |
| 稳态误差 | Ki = 0 / 死区大 / 摩擦 | 加 Ki / 前馈摩擦补偿 |
| 抖动 / 磨损 | D 放大噪声 / 死区小 | 加 D 滤波 / 加死区 |
| 阶跃后长时间不收 | 积分饱和 | 加抗 windup |
| 长直行偏一点 | 偏置 / 风 / 坡 | 加积分 / 前馈 |

## 7. C 代码（嵌入式生产可用）

```c
typedef struct {
    float Kp, Ki, Kd, Ts;
    float u_min, u_max;     // 输出限幅
    float du_max;           // 速率限制
    float Kt;               // 反算抗饱和增益（≈ √(Ki*Kd) 或 1/Ti）
    float N;                // D 滤波系数
    float i_state;          // 积分状态
    float d_state;          // 滤波 D 状态
    float e_prev;
    float u_prev;
} PID_t;

float pid_step(PID_t* p, float r, float y) {
    float e = r - y;
    float P = p->Kp * e;
    // 微分先行：对 -y 求导，避免设定值阶跃
    float d_raw = (-y - p->d_state) / p->Ts;
    p->d_state += p->Ts * p->N * d_raw;             // 一阶低通
    float D = p->Kd * d_raw;

    float u_pre = P + p->i_state + D;
    float u = u_pre;
    if (u > p->u_max) u = p->u_max;
    if (u < p->u_min) u = p->u_min;

    // rate limit
    float du = u - p->u_prev;
    if (du >  p->du_max) u = p->u_prev + p->du_max;
    if (du < -p->du_max) u = p->u_prev - p->du_max;

    // 积分（带反算抗饱和）
    p->i_state += p->Ki * p->Ts * e + p->Kt * (u - u_pre);

    p->e_prev = e;
    p->u_prev = u;
    return u;
}
```

## 8. PID 选型判断

| 系统 | 推荐 |
|------|------|
| 一阶系统（温度、流量） | PI |
| 二阶 / 惯性大 / 噪声小 | PID（带 D 滤波） |
| 噪声大（流量计、视觉） | PI 或 PID + 强滤波 |
| 高动态（电机、姿态） | 串级 PI / PID + 前馈 |
| 强非线性 / 多变量 / 约束 | **MPC**（详见 [MPC 系列](../../mpc/MPC_00_知识图谱与系列总览.md)） |

PID 局限：
* 强耦合 MIMO 难；约束没法显式处理 → MPC。
* 时变 / 强非线性 → 自适应 / 鲁棒 / 学习。

## 10. Top 15 PID 工程 Checklist

1. ☐ 采样周期 `Ts ≤ T_dom/10`，固定中断 / RT 任务。
2. ☐ 优先增量式实现 + 输出限幅 + 速率限制。
3. ☐ 抗 Windup 必加（限幅积分 / 反算）。
4. ☐ D 项加一阶低通（N=8~20）+ 微分先行。
5. ☐ 设定值阶跃 → 加斜坡 / S 曲线。
6. ☐ 死区抑制噪声引起抖动。
7. ☐ 使用浮点要小心溢出 / 数值精度（嵌入式定点亦然）。
8. ☐ 高动态系统用串级（速度 / 电流 / 姿态环）。
9. ☐ 已知动力学加前馈，PID 只补偿误差。
10. ☐ 不同工况 Gain Scheduling。
11. ☐ 调参顺序 P → I → D，记录每次曲线。
12. ☐ 对比指标：上升时间 / 超调 / 稳态误差 / IAE / ITAE。
13. ☐ 异常保护：传感器丢 / 跳变 / 通信断 → 输出保持 / 退保险态。
14. ☐ 调试日志：r、y、e、P、I、D、u、u_sat 全记录。
15. ☐ 单元测试 + HIL 仿真验证；不要实车随便上。

## 面试速记

1. **P 跟得快、I 消静差、D 加阻尼**。
2. **P 太大振荡、I 太大超调、D 太大噪声放大**。
3. **位置式管绝对量、增量式管变化量**。
4. **积分饱和 → 反算 / 限幅 / 条件积分**。
5. **微分先行 + 一阶低通** 是工程标配。
6. **Z-N 临界振荡法**：Ku, Tu → 查表初值。
7. **采样周期 ≤ 时间常数 / 10**。
8. **串级**：内环带宽 5–10× 外环。
9. **前馈 + PID** 一直被低估，强烈推荐。
10. **PID 不会处理约束、不会预测**，约束多 / MIMO 用 MPC。
11. **死区 + 速率限制** 保护执行器。
12. **调参先 P 再 I 再 D**，每步看响应曲线。
