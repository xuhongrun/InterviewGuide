# 机器人工程 最佳实践

> ROS 之外的"机器人通用工程"层：坐标系、传感器、SLAM、规划、控制、安全、上线。可与 [ROS1 最佳实践](../ros1/ROS1%20最佳实践.md) / [ROS2 最佳实践](../ros2/ROS2%20最佳实践.md) 配合。

---

## 1. 坐标系与时间

* **REP-103 / REP-105 强制遵循**：`map → odom → base_link → sensor_link`，右手系，X 前 / Y 左 / Z 上，单位 SI（米、秒、弧度）。
* **TF 树单父**：每个 frame 只有一个父；不要把 `odom` 拆成多支。
* **静态变换**用 `static_transform_publisher`，常量发一次；动态变换走 `/tf`。
* **时间戳**必须填，并使用统一时钟源（PTP / chrony 同步 ≤ 1ms 误差）。
* **使用时刻精确化**：`tf2.lookupTransform(target, source, msg.header.stamp)`，不要 `Time(0)` 取最新（多传感器易错配）。
* **数据回放**用 `--clock` + `use_sim_time=true`，全部节点同步。

## 2. 传感器接入

| 类型 | 关键校准 / 注意 |
|------|------|
| 相机 | 内参（焦距/畸变）+ 外参（相机-base）；曝光固定；ROS msg 用 `image_transport` |
| 激光雷达 | 时间戳每包 / 每点；运动畸变补偿；外参标定（NDT/手眼） |
| IMU | 静止零偏；噪声 σ；与 wheel/lidar 时间对齐 |
| GPS/GNSS | RTK 状态码（fix/float/single）；天线臂偏移；UTM 区切换 |
| 轮速里程计 | 编码器分辨率 + 轮径；打滑监测；融合前给方差 |
| 毫米波雷达 | 反射强度门限 + 跟踪 ID；多目标关联 |

* 标定参数与代码版本绑定（YAML 入仓 + 哈希），上线前重测。
* 传感器**故障检测**：超时、抖动、视场遮挡、温度异常 → 进 Diagnostics。
* 多传感器融合：先时间同步、再外参对齐、再 EKF/UKF/Factor Graph。

详见 [传感器接入实战](传感器接入实战.md)。

## 3. 建图与定位 SLAM / Localization

* **大场景**先建图（离线 / 大算力），上线只跑定位（小算力 + 鲁棒）。
* **2D**：cartographer / slam_toolbox（推荐）；**3D**：LIO-SAM、FAST-LIO2、LIO-LIVOX、Hdl-Graph-SLAM。
* 闭环检测必须验证（旋转 + 平移残差），错闭环比无闭环更糟。
* 地图分块 / 分图层（占据栅格 + 语义层），便于增量更新。
* **定位失效预案**：里程估计接管 N 秒，超时立刻安全停车 / 报警。
* 评估指标：ATE、RPE、ALOAM/EVO 工具。

详见 [建图与定位综述](建图与定位综述.md)。

## 4. 运动规划

* 分层：**全局规划（A*/Dijkstra/Hybrid A* / Theta*）→ 局部规划（DWA / TEB / MPC / Lattice / Frenet）→ 控制**。
* 工业场景：**costmap_2d** + Nav2 / move_base 默认；自动驾驶常用 **Frenet 走廊 + SCP**（[MPC_10](../mpc/MPC_10_自动驾驶_Frenet_走廊_SCP.md)）。
* **运动学约束**必须放进规划器（最小转弯半径、最大加速度、车体长宽）。
* **可重规划频率** ≥ 5 Hz，剧烈环境 ≥ 10 Hz；规划失败要有 fallback。
* 路径平滑（B-Spline / 五次多项式 / Bezier）+ 可控曲率，避免控制端跳变。

详见 [运动规划综述](运动规划综述.md)。

---

## 5. 控制 Control

* **底盘控制**：差速 / 阿克曼 / 全向，分别有运动学逆解模板。
* **PID 入门即可**，关键回路上 **MPC / LQR**；时延 ≥ 50ms 必须建模时延。
* 输出限幅 + 速率限幅 + 死区 + 卡尔曼平滑，避免抖动。
* **安全监控线程**独立优先级最高：超时（>50ms 无指令）立即停车。
* 控制周期与传感器周期对齐（典型 100~500 Hz）；周期抖动 σ < 1ms。

详见 [控制综述](控制综述.md) · [MPC_最佳实践](../mpc/MPC_最佳实践.md)。

## 6. 实时性

* PREEMPT_RT 内核；关键线程 `SCHED_FIFO` 50~80；mlockall 锁内存。
* 控制循环 / DDS 接收线程 pin 到独立核，关闭该核中断。
* CPU 频率定频（performance governor），关闭 C-state 深休眠。
* GPU / DMA 流量隔离，避免抢占总线。
* 测量：cyclictest 周期抖动；hyperfine 端到端延迟；perf sched 跟踪。

---

## 7. 安全 Safety

* **功能安全**：ISO 26262（汽车 ASIL）/ ISO 13849（工业）/ IEC 61508 通用。
* **冗余**：双控、双传感器、双电源；表决 / 切换策略明确。
* **看门狗**：硬件 + 软件双层；超时立即进入安全态。
* **急停**：硬线优先（断电 / 切电机使能）；软急停只是辅助。
* **状态机**：Init / Standby / Active / Safe / Fault；只有明确转移条件。
* **故障树 FTA + FMEA** 在设计阶段做；运行期日志可追溯。
* **安全 SLAM / 安全规划**：地图退化、传感器失效、定位漂移都要兜底。

---

## 8. 仿真与回归

* **Gazebo / Ignition / Isaac Sim / Carla / LGSVL**：选与硬件接口一致的。
* **数字孪生**：从 URDF/SDF 到物理参数（惯量、摩擦、电机）逐项标定。
* **场景库**：边界场景（雨雪、夜间、动态目标）覆盖率指标化。
* **回归 Pipeline**：每次提交跑 N 个场景，KPI（成功率、舒适度、能耗）自动对比 baseline。
* **数据回放**：rosbag2 + 原始传感器流，离线 replay 与算法解耦。

---

## 9. 部署与运维

* **OTA**：A/B 系统分区 + 增量包 + 签名校验 + 失败回滚。
* **版本绑定**：URDF / 标定 / 模型 / 代码 同一 git tag，部署一致性。
* **遥控 / 远程介入**：低延迟 4G/5G 链路 + 安全断连兜底。
* **遥测 Telemetry**：关键指标上云（电池、温度、定位置信度、规划失败率）。
* **告警分级 + 自动 Runbook**：现场首要响应时间 < 5 min。
* **车队管理**：固件版本、参数集、任务分发、地图更新统一平台。

---

## 10. 数据闭环

* **采集**：脱敏后回传典型 / 异常 / corner case；存储成本预算。
* **标注 / 自动伪标签 + 主动学习**：减少人力。
* **再训练 / 再标定**：模型 + 规则 + 阈值同步演进。
* **A/B 评估**：影子模式 → 灰度 → 全量。
* **数据治理**：版本化（DVC / Pachyderm）、血缘可追溯、合规可删除。

---

## 11. 团队协作

* **接口契约先行**：URDF、IDL、Topic 列表、坐标系、单位、频率写在 docs/interface.md。
* **变更评审**：传感器接口 / 安全策略改动必走两人 review。
* **现场调试 SOP**：电源开机顺序、急停校验、低速试运行、日志收集。
* **每次出现场带 rosbag**：故障复现是金。

---

## 12. 反模式 Top 12

1. 不同节点用不同时钟源 → 时间错乱。
2. TF 多父 / 重复发布同一变换。
3. 标定参数硬编码不入仓。
4. 控制无超时保护，离线即失控。
5. 仅依赖 GPS 定位，进隧道即失效。
6. 仿真与真实物理参数差距大，sim2real 失败。
7. 看门狗设得太长（秒级），故障传播。
8. 关键线程未锁内存 / 未提优先级。
9. 急停只走软件，断电时无效。
10. 错闭环没验证，地图被污染。
11. 上线前不跑回归场景。
12. OTA 没回滚，失败砖机。

## 13. Top 20 Checklist

1. ☐ REP-103/105 坐标系与单位规范。
2. ☐ 时间同步（PTP/chrony）误差 < 1ms。
3. ☐ 标定参数 YAML 入仓 + 版本绑定。
4. ☐ 传感器超时 / 异常进 Diagnostics。
5. ☐ TF 树单父，静态变换显式声明。
6. ☐ 定位失效预案（里程估计 + 安全停车）。
7. ☐ 规划失败 fallback + 重规划 ≥ 5 Hz。
8. ☐ 控制限幅 + 速率限幅 + 死区。
9. ☐ 控制周期抖动监控（σ < 1ms）。
10. ☐ 安全监控独立线程最高优先级。
11. ☐ 看门狗硬件 + 软件双层。
12. ☐ 急停硬线优先，软件辅助。
13. ☐ PREEMPT_RT + CPU pin + mlockall。
14. ☐ 仿真回归覆盖典型 + 边界场景。
15. ☐ 数字孪生物理参数标定。
16. ☐ rosbag2 + 离线 replay 标准化。
17. ☐ OTA A/B + 签名 + 回滚。
18. ☐ 车队遥测 + 告警分级 + Runbook。
19. ☐ 数据闭环：采集 → 标注 → 再训练 → 灰度。
20. ☐ 现场 SOP + 故障复现 rosbag 必带。

## 面试速记

1. **REP-103/105** 是机器人坐标 / 单位 / TF 父子关系的硬规范。
2. **时间同步** 是多传感器融合的前提（PTP / chrony / TSC）。
3. **TF 树单父**；动态用 `/tf`，静态用 `static_transform_publisher`。
4. **传感器融合三步**：时间对齐 → 外参对齐 → 滤波。
5. **闭环验证** 比闭环检测更重要，错闭环最致命。
6. **控制安全三件套**：超时停车、限幅、看门狗。
7. **PREEMPT_RT + CPU 隔离 + 锁内存** 是实时控制基础。
8. **急停硬线优先**，软件急停是辅助。
9. **仿真回归 + 场景库 + KPI** 是机器人 CI 的核心。
10. **OTA A/B + 回滚 + 签名** 是车队上线的红线。
