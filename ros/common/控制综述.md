# 控制综述

> 移动机器人 / 自动驾驶 / 机械臂的控制：横向 / 纵向 / 关节控制。本文汇总 PID / Pure Pursuit / Stanley / LQR / MPC / 力控柔顺。

---

## 一、控制框架

```
轨迹（参考）─→ 横向控制(steer) ─→ 车辆/底盘 ─→ 状态反馈
              纵向控制(throttle/brake)
```

层级：
- **跟踪控制**：跟随给定参考轨迹；
- **执行器控制**：从期望加速度/速度到 PWM/扭矩；
- **底层伺服**：电流环 / 速度环 / 位置环。

---

## 二、PID 控制

经典反馈：
$$u = K_p e + K_i \int e\,dt + K_d \dot{e}$$

工程要点：
- **抗积分饱和**（anti-windup）：clamping、back-calculation；
- 微分项**用滤波**避免噪声放大；
- 离散实现 trapezoidal 比 forward Euler 稳定；
- 调参口诀：**先 P 振 → 加 D 抑振 → 加 I 消静差**。

ROS 实现：`control_toolbox::Pid`、`pid_controller`（ros2_control 链式）。

## 三、横向控制（车辆）

### 3.1 Pure Pursuit

几何方法：在路径上前视一段距离 $L_d$ 找目标点，几何求转向角：
$$\delta = \arctan\!\left(\frac{2 L \sin\alpha}{L_d}\right)$$

- $L$ 轴距，$\alpha$ 目标点航向角误差；
- $L_d$ 通常正比于速度：$L_d = k \cdot v + L_{min}$。

优点：简单、稳定；缺点：高曲率/高速跟踪精度差。

ROS2：`nav2_regulated_pure_pursuit_controller`，加了曲率限速、近障减速。

### 3.2 Stanley

```
                       e (横向误差)
   ─────path──────●─────
                  ↘ ψ (航向误差)
                   车
```
$$\delta = \psi + \arctan\!\left(\frac{k \cdot e}{v}\right)$$

更适合**高速 + 低曲率**（DARPA Urban Challenge 一等奖方案）。

### 3.3 LQR

线性二次调节，离散误差状态方程：
$$x_{k+1} = A x_k + B u_k$$
最优反馈 $u = -K x$，其中 $K$ 由 Riccati 方程解出。

横向 LQR 状态：$[e_y, \dot{e}_y, e_\psi, \dot{e}_\psi]$。

优点：多状态联合优化；缺点：线性化误差、约束难处理。

### 3.4 MPC

滚动有限时域 + 约束二次/非线性优化。详见 [mpc/](../../mpc/) 模块（10 篇）：
- 适合 **高速 + 多约束 + 多输入**；
- 计算开销大，需 OSQP / acados / CasADi 实时求解；
- 常用 kinematic bicycle 模型 + Frenet 坐标。

## 四、纵向控制

| 方法 | 用途 |
|------|------|
| PI 速度环 | 简单 |
| 前馈 + PI | 精确（含坡度补偿、风阻补偿） |
| MPC 纵向 | 与 ACC、跟车一体化 |
| 预瞄 + LQR | 多车间距协同 |

加速度 → 油门/刹车 map：标定查表 + 反馈修正。

---

## 五、差速底盘控制

输入 `Twist (vx, wz)` → 左右轮速：
$$v_l = v_x - \frac{w_z \cdot d}{2}, \quad v_r = v_x + \frac{w_z \cdot d}{2}$$
$d$ 为轮距。

ROS2：`diff_drive_controller`（ros2_control）实现并发布 odom + tf。

---

## 六、Ackermann 车辆

转向几何：
$$\delta = \arctan\!\left(\frac{L \cdot \kappa}{1}\right)$$
$\kappa$ 曲率，$L$ 轴距。

ROS2：`ackermann_steering_controller` / `bicycle_steering_controller` / `tricycle_controller`。

---

## 七、机械臂关节控制

| 模式 | 命令 |
|------|------|
| Position | 关节角 |
| Velocity | 关节速度 |
| Effort（torque） | 力矩 |
| Trajectory | 时间轨迹（MoveIt 主用） |

ros2_control：
- `joint_trajectory_controller` — 接收 `FollowJointTrajectory` action；
- `effort_controllers/JointGroupEffortController`；
- `velocity_controllers/JointGroupVelocityController`。

执行器内部：电流环（μs）→ 速度环（ms）→ 位置环（ms）。

---

## 八、力控 / 阻抗 / 导纳

| 方法 | 模型 |
|------|------|
| **Hybrid Position/Force** | 任务空间分区 |
| **Stiffness / Compliance** | $F = K \Delta x$（虚拟弹簧） |
| **Impedance Control** | $M\ddot{x} + D\dot{x} + Kx = F_{ext}$（外力 → 位置响应） |
| **Admittance Control** | 输入力，输出位置（与 impedance 对偶） |

ROS2：`admittance_controller`（ros2_control）。

应用：装配、打磨、人机协作。

---

## 九、扰动抑制 / 鲁棒控制

| 方法 | 思想 |
|------|------|
| **DOB (Disturbance Observer)** | 估计扰动并补偿 |
| **ADRC (Active Disturbance Rejection Control)** | 扩展状态观测器 + 非线性反馈 |
| **H∞** | 频域优化 |
| **Sliding Mode** | 滑模到滑面，抗扰动强但抖振 |
| **Adaptive (MRAC, L1)** | 在线辨识参数 |

工业最常见：**PID + DOB**。

## 十、状态估计与控制耦合

控制需要稳定的状态：
- 位置：`/odom`、`/amcl_pose`；
- 速度：里程计 / IMU；
- 状态融合：`robot_localization` (EKF/UKF)；
- 时延补偿：用 `now() - measurement.stamp` 调整。

控制器频率 ≥ 状态频率 的 2-5 倍，否则混叠。

---

## 十一、调参流程

1. 模型识别（开环阶跃响应）：测时间常数 / 增益；
2. 用 Ziegler-Nichols 或 SIMC 给初始 PID；
3. 加扰动测试稳态误差 / 超调；
4. 加测量噪声 / 不确定性测鲁棒性；
5. 高速 / 满载工况复测；
6. 上 LQR/MPC 之前**先 PID 调好底层**。

---

## 十二、常见坑

| 现象 | 排查 |
|------|------|
| 速度抖振 | 微分噪声；加 LPF；降 D |
| 大转向时跟踪差 | Pure Pursuit Ld 太大；MPC horizon 太短 |
| 起步爬坡掉速 | 没有前馈坡度补偿 |
| 高速横摆 | LQR 权重不当 / 模型线性化范围超 |
| MPC 求解超时 | 减 horizon / warm start / 预编译 acados |
| 力控发散 | 阻抗矩阵 K/D 不当；FT 滤波延迟大 |

---

## 十三、面试速记

- 横向：低速 **Pure Pursuit**，高速 **Stanley / LQR / MPC**
- 纵向：**前馈 + PI**，进阶 MPC ACC
- 差速：`diff_drive_controller`；Ackermann：`ackermann_steering_controller`
- 机械臂：`joint_trajectory_controller` 主用；柔顺 **admittance_controller**
- 鲁棒：**PID + DOB**；进阶 ADRC / H∞ / Sliding Mode
- MPC 求解器：**OSQP / acados / CasADi**（详见 [mpc/MPC_03_QP问题构建与求解](../../mpc/MPC_03_QP问题构建与求解.md)）
- 控制循环硬实时：**PREEMPT_RT + chrt + 预分配内存**（不在 update 内 malloc）
