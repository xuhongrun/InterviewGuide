# 建图与定位综述

> SLAM (Simultaneous Localization and Mapping) 与定位是机器人移动的基础。本文综述 2D/3D 主流算法、对比、选型、与 ROS 实现的对应。

---

## 一、问题分层

```
                    SLAM
                /          \
       前端（数据关联）    后端（优化）
        ├─ 特征提取            ├─ EKF
        ├─ 帧间配准            ├─ 粒子滤波
        ├─ 闭环检测            ├─ 图优化（g2o/Ceres/GTSAM）
        └─ 局部建图            └─ 因子图
```

| 类别 | 说明 |
|------|------|
| **Filtering-based** | EKF-SLAM, FastSLAM, PF | 早期，规模有限 |
| **Graph-based** | 节点=位姿，边=相对约束，全局优化 | 当前主流 |
| **Visual SLAM** | 单/双目/RGB-D | ORB-SLAM3 / VINS / DSO |
| **Lidar SLAM** | 2D/3D 激光为主 | Cartographer / slam_toolbox / LIO-SAM / Fast-LIO |
| **Tightly-coupled VIO/LIO** | 视觉/激光 + IMU 紧耦合 | VINS-Mono / Fast-LIO 2 |

---

## 二、2D SLAM 比较

| 算法 | 类型 | 特点 |
|------|------|------|
| **gmapping** (ROS1) | 粒子滤波 (RBPF) | 简单，已停维护 |
| **hector_slam** | 扫描匹配 | 不需 odom，依赖高频激光 |
| **karto** | 图优化 | slam_toolbox 前身 |
| **slam_toolbox** | 图优化 + 序列化 + lifelong | **ROS2 推荐** |
| **Cartographer 2D** | 子图 + 图优化 | 谷歌出品，回环优秀 |

选型：
- 室内仓储 / AGV → **slam_toolbox**
- 高动态 / 复杂场景 → **Cartographer**
- 简单平台教学 → gmapping/hector

---

## 三、3D SLAM 比较

| 算法 | 输入 | 特点 |
|------|------|------|
| **LOAM** | LiDAR | 经典，特征点 edge/plane |
| **LeGO-LOAM** | LiDAR | 地面优化 |
| **LIO-SAM** | LiDAR + IMU | 紧耦合，因子图 |
| **Fast-LIO 2** | LiDAR + IMU | 高频实时，IEKF |
| **LVI-SAM** | LiDAR + Vis + IMU | 多模态融合 |
| **Cartographer 3D** | 多 LiDAR + IMU | 谷歌 |
| **Open3D-SLAM** | LiDAR | 教研 |
| **HDL-Graph-SLAM** | LiDAR | 完整 ROS pipeline |
| **R3LIVE** | LiDAR + Vis + IMU | 彩色稠密重建 |

工业部署优先：**Fast-LIO 2 / LIO-SAM**；多模态：**R3LIVE / LVI-SAM**。

---

## 四、视觉 SLAM 比较

| 算法 | 传感器 | 特点 |
|------|--------|------|
| **ORB-SLAM3** | 单/双/RGB-D + IMU | 闭环好，已商用化分裂 |
| **VINS-Fusion** | 单/双 + IMU | 港科开源，融合好 |
| **OpenVSLAM / Stella-VSLAM** | 多种 | ORB-SLAM 衍生 |
| **DSO / DSO-Stereo** | 直接法 | 弱纹理强 |
| **SVO 2** | 半直接 | 实时性好 |
| **OKVIS** | 双 + IMU | 工业 |
| **Kimera** | 立体 + IMU | 多功能（语义） |

视觉 SLAM 弱点：弱光、高速、长时漂移；常配合 IMU/LiDAR。

---

## 五、闭环（Loop Closure）

- 视觉：词袋 (BoW) — DBoW2/3、NetVLAD；
- 激光：scan context、segmatch、loop3d；
- 全局描述子越好 → 召回越高；
- 闭环验证：几何一致性 + RANSAC + 最小内点阈值；
- 闭环成功后做位姿图优化（g2o / Ceres / GTSAM）。

## 六、定位（已有地图）

| 方法 | 输入 | 备注 |
|------|------|------|
| **AMCL** | 2D 占用栅格 + 激光 | 粒子滤波，ROS 经典 |
| **slam_toolbox localization** | 2D 占用栅格 + 激光 | 图优化，鲁棒 |
| **NDT scan-matcher** (Autoware) | 3D 点云图 + LiDAR | NDT 配准 |
| **Fast-LIO LOC / hdl_localization** | 3D 点云图 | 实时性好 |
| **视觉 relocalization** | 视觉地图 (BoW/NetVLAD) | 弱光不行 |
| **GNSS-INS** | RTK + IMU | 室外开阔场景最佳 |
| **UWB / Beacon** | 锚点测距 | 室内补充 |

## 九、评估指标

| 指标 | 含义 |
|------|------|
| **ATE (Absolute Trajectory Error)** | 与真值整体对齐后误差 |
| **RPE (Relative Pose Error)** | 局部段间误差，反映漂移 |
| **Translation/Rotation 分量** | 平移/旋转分别评估 |
| **AOR (Average Orientation Error)** | 角度误差 |
| **Map IoU** | 地图与真值占用一致 |

工具：
```bash
evo_traj tum traj.txt --plot
evo_ape tum gt.txt traj.txt --align --plot
evo_rpe tum gt.txt traj.txt --align --pose_relation trans_part
```

## 十、工程化要点

- **传感器同步**：硬件触发 / PTP / PPS；
- **运动补偿**：LiDAR 必须，每点时戳；
- **IMU 标定**：Allan + 静态初始化；
- **外参标定**：cam-IMU、LiDAR-IMU、LiDAR-Cam；
- **回环阈值**：召回 vs 误回；
- **存储 / 序列化**：长期建图（lifelong），增量保存；
- **大场景**：分块加载 / 子图 / OctoMap 八叉树；
- **退化场景**：长走廊、动态人群 → 增加 IMU/视觉/UWB 辅助。

## 十一、面试速记

- 2D SLAM 用 **slam_toolbox**（替代 gmapping）
- 3D SLAM 用 **Fast-LIO 2 / LIO-SAM**；多模态 R3LIVE / LVI-SAM
- 视觉用 **ORB-SLAM3 / VINS-Fusion**
- 已有地图定位：2D `amcl` 或 `slam_toolbox-loc`；3D NDT / hdl_localization
- 闭环：BoW / Scan Context + 几何验证 + 图优化
- 评估用 **evo**（ATE / RPE）
- 工程命门：**时间同步、运动补偿、外参标定**
- 与 MPC/Control 衔接见 [运动规划综述](运动规划综述.md)、[控制综述](控制综述.md)
