# 运动规划综述

> 机器人 / 自动驾驶规划三层：全局（global）/ 局部（local）/ 运动学（trajectory）。本文汇总主流算法与适用场景。

---

## 一、规划层级

```
任务/全局 ─→ Behavior（决策）─→ 路径规划 ─→ 轨迹优化 ─→ 控制
   ↑                                                        ↓
mission/Lanelet2                                       MPC / PID
```

| 层级 | 输出 | 时长 |
|------|------|------|
| Mission | 路径序列 | 分钟级 |
| Behavior | 跟车/换道/避障 | 秒级 |
| Path | 几何路径（无时间） | 100ms |
| Trajectory | (x,y,t) 含速度加速度 | 50ms |
| Control | 油门/转向/扭矩 | 10ms |

---

## 二、搜索类（基于图）

| 算法 | 特点 |
|------|------|
| **Dijkstra** | 无启发式，最短路径，全图扫描 |
| **A\*** | 启发式，需可采纳启发函数 |
| **Hybrid A\*** | 含朝向（θ），适用 Ackermann/差速 |
| **Theta\*** | 任意角度路径（不限格点 8 邻域） |
| **D\* Lite** | 增量重规划，应对动态环境 |
| **JPS (Jump Point Search)** | 加速 A* 在均匀栅格 |
| **State Lattice** | 预生成运动基元 + 图搜索 |

ROS 实现：
- `nav2_navfn_planner` — Dijkstra
- `nav2_smac_planner` — A* / Hybrid A* / Lattice
- `nav2_theta_star_planner` — Theta*

---

## 三、采样类（连续空间）

| 算法 | 特点 |
|------|------|
| **PRM (Probabilistic Roadmap)** | 多查询，预建图 |
| **RRT** | 单查询、快速、不最优 |
| **RRT\*** | 渐近最优 |
| **Informed RRT\*** | 焦点采样加速 |
| **BIT\*** (Batch Informed Trees) | 当前 SOTA 之一 |
| **FMT\*** | Fast Marching Trees |
| **EST** | Expansive Spaces |

适用：高维（机械臂 6/7-DoF）、复杂约束。

ROS 实现：**OMPL** 库 + MoveIt（机械臂）；底盘较少用采样规划。

---

## 四、优化类

| 算法 | 思想 |
|------|------|
| **CHOMP** | 协变梯度，优化平滑 + 避障代价 |
| **STOMP** | 随机采样轨迹优化（无梯度） |
| **TrajOpt** | SQP 序列二次规划 |
| **iLQR / DDP** | 微分动态规划 |
| **MPC** | 滚动有限时域优化（详见 [mpc/](../../mpc/)） |
| **SCP (Sequential Convex Programming)** | 自动驾驶常用，凸近似 |

适用：高维平滑要求、约束复杂、性能可调。

---

## 五、汽车专用

| 算法 | 用途 |
|------|------|
| **Dubins / Reeds-Shepp** | 最短曲线（最小转弯半径） |
| **Frenet 框架** | 在车道线坐标系（s, l）规划，便于换道 |
| **Quintic / Quartic 多项式** | 单段平滑轨迹 |
| **EM Planner** (Apollo) | Frenet + DP + QP |
| **Lattice Planner** | Frenet + 多采样 |
| **PolyFit + Optimization** | Apollo Public Road Planner |

参考 [MPC 自动驾驶 Frenet 走廊 SCP](../../mpc/MPC_10_自动驾驶_Frenet_走廊_SCP.md)。

## 六、局部规划（避障）

| 算法 | 特点 |
|------|------|
| **DWA (Dynamic Window)** | 速度采样 + 评分，差速最佳，快 |
| **TEB (Timed Elastic Band)** | 弹性带优化 + 时间，可处理 Ackermann |
| **MPPI (Model Predictive Path Integral)** | 采样 MPC，鲁棒 |
| **RPP (Regulated Pure Pursuit)** | 跟踪型，简单 |
| **Elastic Band** | 路径变形避障 |

ROS2 Nav2：
- `dwb_core` — DWA
- `nav2_mppi_controller` — MPPI
- `nav2_regulated_pure_pursuit_controller` — RPP

---

## 七、机械臂规划

| 工具 | 算法 |
|------|------|
| **MoveIt OMPL** | RRTConnect 默认 |
| **MoveIt Pilz** | LIN / PTP / CIRC 解析（工业确定性） |
| **MoveIt STOMP / CHOMP** | 优化平滑 |
| **TrajOpt** | SQP |
| **TOPP-RA** | 时间最优重参化 |

约束：
- 关节限位 / 速度 / 加速度；
- 末端工件夹持（Tool path）；
- 障碍 / 自碰撞（ACM）；
- 任务空间约束（保持工具垂直）。

## 八、动态环境与多智能体

| 方法 | 用途 |
|------|------|
| **D\* Lite / Anytime D\*** | 增量重规划 |
| **MPC + 预测障碍轨迹** | 与 perception/prediction 联合 |

| **Open-RMF traffic schedule** | 车队规则化协调 |
| **CBS (Conflict-Based Search)** | 多机器人路径规划 |

## 十、选型 Cheat Sheet

| 场景 | 推荐 |
|------|------|
| 室内 AGV 差速 | NavFn + DWA / RPP |
| Ackermann 仓储车 | Smac Hybrid A* + MPPI |
| 自动驾驶 | Lattice + SCP / Apollo EM |
| 机械臂工业 | Pilz LIN/CIRC |
| 机械臂科研 | OMPL RRTConnect / STOMP |
| 多机器人协同 | Open-RMF / VO/RVO |
| 动态闹市 | D* Lite + MPC + 行人预测 |
| 高维（无人机/3D） | RRT* / BIT* / OMPL |
